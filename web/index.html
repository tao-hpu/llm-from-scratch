CHAPTER 13

第 13 章 · 线性注意力:把 KV cache 换成固定大小的记忆板

全注意力推理时每个 token 都要存 K/V,上下文越长 cache 越大。线性注意力每个头只留一块 32×32 的记忆板:写入是加一个外积,delta rule 先擦再写,遗忘门 α 按比例衰减,合起来就是 Qwen3-Next 用的 Gated DeltaNet。配套代码 11_linear_attn.py,9 组真实训练:测试长度拉到 512,全注意力 val loss 涨到 3.52,GDN 停在 1.53;键值检索 N=32 时 GDN 答对 99.9%,只加不减的 linear 16.6%。最后看工业界为什么用 3:1 混合。

CHAPTER 14

第 14 章 · 稀疏注意力:每个 query 只挑一部分历史去读

K/V 照样全存,每个 query 只挑一小部分去算。照 DeepSeek 的 NSA 手写三条支路:压缩给每块留摘要、挑选只细看 top-n 块、滑窗兜住最近的字,再用 sigmoid 门加权。配套代码 12_sparse_attn.py:256 上下文平均每个 query 读 76.8 个 key(全注意力 128.5);远处找钥匙任务上只滑窗 3.1%(乱猜),NSA 99.85%。再对照 DSA、DeepSeek-V4 的 CSA/HCA 与 Qwen3.8 的 QSA。

CHAPTER 16

第 16 章 · 投机解码与 MTP:先便宜地猜,再一次验收

自回归生成每吐一个字都要跑一次主模型。投机解码让草稿员先猜 γ 个字,主模型一次 forward 算出这些位置的 p,以 min(1, p/q) 接受、拒绝就从 max(0, p−q) 重抽,输出分布不变。配套代码 14_mtp.py,在 RTX 4090 上实测:1 层小草稿模型接受率 0.667–0.745,γ=6 时每次主 forward 吐 3.09 个字;DeepSeek-V3 式 MTP 头接受率 0.899,墙钟 1.27×;20 万次模拟后与 p 的总变差距离 0.0005。最后算清玩具规模下省了 forward 为什么没怎么省时间。

共 5 步
  • STEP 1一次 forward 验收一串→
  • STEP 2接受规则:min(1, p/q)→
  • STEP 3γ 猜几个→
